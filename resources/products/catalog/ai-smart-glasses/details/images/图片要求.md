# 商品详情图片要求

建议宽度 1200–1600 px，高度不限；页面保持原始比例竖排，手机端会缩放到屏幕宽度。图片内如有小字，请检查手机上是否清晰；说明文字优先写入详情 JSON 的文字块。

支持 WebP、JPG、JPEG、PNG、AVIF、SVG；照片建议 WebP，单张建议小于 500 KB，长详情图建议小于 1 MB。文件名建议使用 01.webp、02.webp 等小写英文与数字名称。

此文件夹与上一级 config.json 配套。图片路径相对于详情文件夹，例如 images/01.webp。增加图片后，在 config.json 的 blocks 数组中新增 image 块；数组顺序决定图文展示顺序，未引用的图片不会出现在详情里。没有配置文件或 blocks 为空时，按图片文件名数字顺序显示。

图片和 JSON 会随网站发布，请只放公开的商品资料。详情 JSON 的填写示例见项目根目录 CONTENT-GUIDE.md。
